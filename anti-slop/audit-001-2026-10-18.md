# antislop audit 001

- Date: 2026-10-18
- Mode: **after** (global preference)
- Scope: `scm-modern` (Next.js 14 app). Reviewed all pages under `app/`, `components/**`, `app/globals.css`, `tailwind.config.ts`, and the copy in `lib/catalog.ts` / `lib/settings.ts`.
- Design Read (inferred, not supplied): a crypto cloud-mining landing + console for retail buyers, in a dark gold-on-ink "web3 premium" language. No `DESIGN.md` exists, so the dials were never declared (see finding 5).
- Method: source inspection plus computed contrast (skill checker). No files changed.

Priority key: **HIGH** = Hard Gate (absolute), **MEDIUM** = Purpose-Gate (technique needs a written reason), **LOW** = Quality Lock / consistency.

## HIGH (Hard Gate)

**1. R-02, em dash used as a connector throughout the UI copy and metadata.**
Instances include `app/layout.tsx:11` (page title), `app/page.tsx:69,190,197`, `app/register/page.tsx:41,61`, `app/affiliate/page.tsx:19,33`, `app/contact/page.tsx:22`, `app/withdrawal/page.tsx:22`, `app/invoice/[hash]/page.tsx:70`, `components/site-chrome.tsx:64,91,92,93`, `app/account/page.tsx:76`, `app/payouts/page.tsx:38`, `components/faq-list.tsx:11`. R-02 bans the character outright; each needs a comma, colon, period, or parentheses.

**2. R-25, low-contrast text below WCAG AA.**
`text-slate-500` (23 usages, small text) computes 4.23:1 on `#05070d`, 3.96:1 on `ink-900`, 3.07:1 on the glass surface, all below the 4.5:1 floor. The error string in `components/purchase-button.tsx:30` uses `text-red-600`, which computes 4.17:1 on `#05070d` (fails; every other error message uses `red-300`, which passes at 10.61:1).

**3. R-17, a statistic with no real source.**
`components/site-chrome.tsx:72` ("99% uptime fleet") is an invented number. R-17 requires a real source or no number at all.

**4. R-36, fabricated trust and performance claims.**
`components/site-chrome.tsx:69` "Audited payouts" and `:72` "99% uptime fleet" assert audit and uptime that nothing evidences. `:64` "institutional-grade" is the same class of unsupported claim.

**5. R-37, no design direction and the result is not labeled a draft.**
No `DESIGN.md` or written brand direction exists, and the design is presented as a finished "Flagship Edition", not a "draft without direction". R-37 requires loading direction before building, or labeling the output and pinning the honest dials ENERGY 1 / RHYTHM 1 / MOTION 1.

**6. R-03, tap targets below the 44px minimum.**
`components/copy-button.tsx:19` (`h-9`, 36px), `components/ui/button.tsx:17` (`sm: h-9`, 36px), and `components/mobile-nav.tsx:14` (`p-2.5` around a 20px icon, roughly 40px) are under the touch minimum on phones. Admin tables also use tiny `p-1` cells.

## MEDIUM (Purpose-Gate)

**7. R-10, glassmorphism applied far past the dose cap.**
`glass` appears on 34 elements, including the sticky navbar (`site-chrome.tsx:10`), every card (`components/ui/card.tsx:7`), the mobile menu panel (`mobile-nav.tsx:19`), and dozens of pills. R-10 allows blur on at most 1 to 2 elements, never navbar plus cards plus modal at once.

**8. R-13, glow spread across buttons, cards, and background.**
Gold shadows on buttons (`card.tsx` shadow, `button.tsx:10`, header CTA `site-chrome.tsx:40`), `gold-ring` on popular cards and dashboard tiles (`globals.css:53`), and blurred gold orbs behind sections (see finding 10). R-13 caps glow at 1 to 2 focus elements.

**9. R-07, decorative background grid.**
`.grid-bg` (`globals.css:32`) draws a blueprint grid behind the hero, login, and register panels with no stated identity purpose. R-07 forbids grid/blueprint backgrounds used as default texture.

**10. R-01, radial orbs and a 3-color ambient gradient as default decoration.**
`bg-scene` (`globals.css:25-31`) stacks gold, sky, and emerald radial gradients, and blurred orbs sit behind the hero (`app/page.tsx:58-59`), CTA (`:227`), login (`app/login/page.tsx:39`), register (`app/register/page.tsx:52`), and affiliate hero (`app/affiliate/page.tsx:13`). This is the "colored glow background plus radial orbs" default; it needs a written hierarchy/brand reason to stay.

**11. R-09, eyebrow badge above the H1 and status-style capsules.**
`app/page.tsx:61-63` parks a Sparkles pill ("Flagship cloud mining · ARIA") directly above the headline that already says it, which R-09 calls out by name. Similar capsules: "Most popular" (`:144`), "Free forever" (`:149`).

**12. R-06, default typefaces and wide-tracked uppercase labels.**
`app/layout.tsx:6-7` uses Inter and Space Grotesk, both on the AI-default roster, with no written reason. Uppercase `tracking-[0.2em]` / `tracking-widest` labels repeat across nearly every section ("HASHRATE MARKETPLACE", "MINING CONSOLE", "CONTROL TOWER", "LEDGER", "KNOWLEDGE BASE"), the pattern R-06 flags.

**13. R-19, endless motion with no user trigger.**
`animate-marquee` (page.tsx:105), `animate-floaty` (page.tsx:58), `animate-pulseGlow` and `animate-pulse` (dashboard:153,164), and the `shimmer` loop (`globals.css:78`) all run forever. The dashboard rig dot (`dashboard:153`) is a decorative pulsing status light with a glow; R-19 allows one dot marking real state, without the glow and without the endless pulse.

**14. R-12, large shadow on nearly every surface.**
Every card carries `shadow-[0_20px_60px_-30px_rgba(0,0,0,0.9)]` (`card.tsx:7`) and buttons carry gold shadows, so the page floats throughout. R-12 wants shadow as a selective elevation marker.

**15. R-08, arrows on almost every CTA.**
`ArrowRight` on the hero, CTA, login, and register buttons, `ArrowUpRight` in the dashboard, and literal "→" in copy (`page.tsx:127`, `faq/page.tsx:21`). R-08: not every button needs a direction cue.

**16. R-04, single default icon library plus a generic glyph.**
Every icon is from Lucide (Pickaxe, Sparkles, Zap, ShieldCheck, Gift, Percent, Link2, Activity, and so on), chosen as the library look; `Sparkles` (`page.tsx:8,62`) is on the generic-AI list. R-04 asks for relevance per icon, written down.

**17. R-23, logo and favicon created without confirmation.**
The mark is a generated Pickaxe glyph in a gold tile (`site-chrome.tsx:13`), and `app/favicon.ico` is the untouched create-next-app default. R-23 requires confirming a logo before treating it as final, or an honest `[LOGO]` placeholder.

**18. Leftover operator note rendered to users (not just a comment).**
`app/admin/page.tsx:54-57` prints "Operator note: gate /admin behind an is_admin profile check..." as visible UI text. It is an internal instruction shown to anyone in the console, and it is now stale (the guard shipped in commit `eb612fc`).

## LOW (Quality Locks, consistency)

**19. R-05, template section order and rhythm.**
Home is hero → stat row → payout ticker → three pricing columns (middle highlighted) → three identical feature cards → CTA → multi-column footer, with the same "centered eyebrow + title + card grid" rhythm every section. Section composition does not vary.

**20. R-14, identical feature cards.**
The three cards in `app/page.tsx:208-222` share size, icon treatment, and layout; `app/affiliate/page.tsx:31-42` repeats the pattern with `01/02/03` round-icon steps.

**21. R-16, vague marketing vocabulary.**
"institutional-grade" (`site-chrome.tsx:64`), "Flagship" repeated (title, badges), "transparent on-chain payouts" used as a claim. Prefer specific, evidenced language.

**22. R-21, dark forced with no toggle and no written reason.**
`app/layout.tsx:24` hard-codes `dark` and `globals.css:6` sets `color-scheme: dark`, with no theme toggle. If a fixed theme is intended, the reason should be written; otherwise ship a working toggle.

**23. R-20 / R-30, no distinctive identity.**
Swap the logo and product name and the result still reads as a generic dark-gold crypto template; there is no identity motif beyond gold plus orb glow. Logic mirrors a generic web3 layout rather than a decided identity.

**24. R-29, more accents than the cap allows.**
Gold plus sky plus emerald as equal accents, plus violet (`admin/page.tsx:52`), amber (`:49`), and red. R-29 wants 2 to 3 core colors plus one accent.

**25. R-31, reasons were never written down.**
No one-line justification exists for the palette, type, or layout choices; the keystone rule wants each recorded.

**26. Code comments (antislop-code).**
Em dashes inside comments (`lib/catalog.ts:8`, `app/dashboard/page.tsx:67`, `app/admin/page.tsx:38`), multi-line doc blocks that run past two lines (`lib/auth.ts:3-8`, `lib/ensure-profile.ts:3-11`, `lib/catalog.ts:6-10`), and bare section labels (`globals.css:24,66,86`). Trim to the one-line fact.

**27. Admin tables are raw schema dumps.**
`app/admin/plans/page.tsx:16-26` and `app/admin/transactions/page.tsx:13-14` print DB column names and raw `String(...).slice(0,60)` values. Antislop-ui's "generic table columns" pattern: columns should follow the decision the operator makes, not the table shape.

**28. R-27, empty admin states say nothing.**
Admin tables show `(0)` with an empty grid and no message or next action, where R-27 wants an empty state that names the cause.
